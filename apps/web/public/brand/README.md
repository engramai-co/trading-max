# Trading Max brand assets

The approved v1 mark is a geometric `T + M` monogram:

- graphite `#171A21` for the `T`;
- cobalt `#2563EB` for the `M`;
- cyan `#22D3EE` for the small terminal tip;
- warm ivory `#F4F2E8` for light-background previews.

`trading-max-primary.png` is the approved raster reference supplied during
the v1 design review. The deterministic SVG files are the source assets for
new product surfaces:

- `trading-max-symbol.svg` — full-colour standalone symbol;
- `trading-max-symbol-mono.svg` — current-colour monochrome symbol;
- `trading-max-lockup.svg` — light-background horizontal lockup;
- `trading-max-lockup-dark.svg` — dark-background lockup;
- `trading-max-app-icon.svg` — square source for favicon and desktop icons;
- `trading-max-social.svg` — 1200 × 630 social preview;
- `trading-max-engram-lockup.svg` — optional `an Engram project` endorsement.

Do not add K-lines, arrows, coins, bull/bear illustrations, or currency signs
to the primary mark. Product status colours are not brand colours.

The wordmark uses a system sans fallback so the SVG remains self-contained;
production brand exports should preserve the same optical proportions and use
the same approved colour values.
