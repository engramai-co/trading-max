# UI component source

Generated shadcn component source lives in this directory.

- CLI: `shadcn@4.23.0` (pinned exact in [package.json](../../package.json))
- Style: `base-luma` ([components.json](../../components.json))
- Primitives: `@base-ui/react`
- Icons: `lucide-react`
- Theming: CSS variables (`tailwind.cssVariables: true`, mapped in `app/shadcn-theme.css`)
- Components added so far:
  - `button.tsx` — generated via `shadcn@4.23.0 add button` (`base-luma`, `@base-ui/react/button`), adapted to `DESIGN.md` Palette A tokens, Luma pill geometry, 40/44/32 control sizes, single 2px focus ring, width-stable loading, plus `CloseButton`
  - `copy-button.tsx` — project wrapper over `Button` following Modern Web Guidance `copy-button` (`command="--copy"` / `commandfor` with Safari 16.4 click fallback, Clipboard API + `execCommand` fallback, sibling `role="status"` live region)
  - `text-link.tsx` — shared `TextLink` component supporting workspace `Link`, external anchors, and inline prose links
  - `input.tsx`, `input-group.tsx`, `textarea.tsx`, `field.tsx` — generated via `shadcn@4.23.0 add input input-group textarea field` (base-luma), with its Label dependency. Apply field fill, outline and sizing through `app/styles/20-fields.css`.
  - `checkbox.tsx`, `switch.tsx`, `tabs.tsx`, `toggle-group.tsx` (+ `toggle.tsx`), `radio-group.tsx` and `progress.tsx` — generated via `shadcn@4.23.0 add checkbox switch tabs toggle-group radio-group progress` from the [Base Luma registry](https://ui.shadcn.com/), backed by `@base-ui/react`. Adapted to the shared Palette A tokens, workspace sliding selection, labelled native-button hit targets and saving feedback.
  - `dialog.tsx`, `alert-dialog.tsx`, `sheet.tsx`, `drawer.tsx` — generated by `shadcn@4.23.0 add dialog alert-dialog sheet drawer` from `base-luma`. Sheets use Base UI Dialog, and bottom drawers use Base UI Drawer for swipes. Workspace titles, close controls and dismissal policy are composed in `workspace/overlay.tsx`.
  - `popover.tsx`, `dropdown-menu.tsx`, `tooltip.tsx`, `hover-card.tsx` — generated by `shadcn@4.23.0 add popover dropdown-menu tooltip hover-card` from `base-luma`. Hover Card wraps Base UI Preview Card. All overlay primitives use the Palette A surfaces and motion in `app/styles/18-overlay.css`.
  - `collapsible.tsx` and `table.tsx` — generated with `shadcn@4.23.0 add collapsible table` from base-luma. Charts use shared pill buttons for disclosures and a labelled scroll region for records.
  - `select.tsx`, `combobox.tsx` and `native-select.tsx` — generated via `shadcn@4.23.0 add select combobox native-select` from the Base Luma registry. Apply the shared field tokens and picker styles in `app/styles/21-pickers.css`.
  - `avatar.tsx`, `empty.tsx`, `pagination.tsx`, `skeleton.tsx`, `spinner.tsx`, and `toast.tsx` — generated via `shadcn@4.23.0 add avatar empty pagination skeleton spinner toast` from [Base Luma](https://ui.shadcn.com/). Avatar and Toast use Base UI. Pagination uses native buttons for in-place records, Skeleton preserves workspace loading timing, and Empty preserves headings and recovery actions. Toast is for optional, non-interrupting action feedback.

The MaxAI conversation uses [assistant-ui](https://www.assistant-ui.com/docs/runtimes/ai-sdk/v7) with `@assistant-ui/react@0.15.38` and its AI SDK 7 adapter `@assistant-ui/react-ai-sdk@1.4.25`, both pinned from the npm registry. The thread and tool rendering primitives wrap the existing Pydantic AI streaming transport. The sidebar uses the same Base Luma button, Sheet and AlertDialog primitives as the workspace.
