# Maintainers

## Current maintainers

- Yuhan Wang — project lead and release owner

The organization has an additional repository administrator for account
continuity. Repository administration does not make that account a product
maintainer and does not add a second-person merge requirement; the release
owner authorizes merges after required checks pass.

## Responsibilities

Maintainers:

1. triage issues and pull requests;
2. protect financial-data correctness and backwards compatibility;
3. review privacy and security impact;
4. maintain CI, migrations, backup and release tooling;
5. publish releases and security advisories;
6. document major decisions.

## Service targets

These are best-effort targets, not paid support:

- security report acknowledgement: 2 business days;
- new issue triage: 7 days;
- community pull-request first response: 14 days.

## Becoming a maintainer

Candidates should contribute consistently, demonstrate good judgement around
financial correctness and privacy, and be invited by existing maintainers.
